# AgentsIA — Operational knowledge router

## Purpose

Load the minimum actionable knowledge for the task. This folder links to canonical documents; it never replaces Framework contracts, Evidence or sprint deliverables.

## Load sequence

1. Read `AGENTS.md`.
2. Select only the domain documents needed.
3. Follow `Load Next` to a contract or named historical sprint only when required.

| Task | Load |
|---|---|
| Domain | [Domain](Domain.md), [Contracts](Contracts.md) |
| Data / SQL | [Data](Data.md), [Database](Database.md), [Contracts](Contracts.md) |
| Service / MFA | [Development](Development.md), [Security](Security.md), [Email](Email.md) |
| OAuth | [OAuth](OAuth.md), [Authentication](Authentication.md), [WebAPI](WebAPI.md) |
| Logging | [Logging](Logging.md), [Observability](Observability.md), [Framework](Framework/README.md) |
| UI | [UI](UI.md), [Testing](Testing.md) |

## Do Not Load

Do not default-load `Sprints/ANCHORED-SUMMARIES-ARCHIVE.md`, `Sprints/ARCHIVE`, immutable Evidence, or unrelated domains.
