# BUG-017.1.3 — JWT `kid` Missing — Análisis End-to-End

---

## 1. Executive Summary

**BUG-017.1.3** se diagnosticó como **FALSO POSITIVO** tras un análisis exhaustivo de todo el pipeline JWT en PassPlat + CBP Authentication.

**Hallazgo principal**: El error `IDX10517` (Signature validation failed — kid is missing) **NO ocurre en el código limpio**. La autenticación JWT funciona correctamente vía HTTPS.

**Causa real del 401**: `UseHttpsRedirection()` en `Program.cs:233` redirige requests HTTP (puerto 5000) a HTTPS (puerto 5001). Durante la redirección cross-scheme (307), el header `Authorization: Bearer` se pierde. La request reenviada a HTTPS llega sin autenticación → 401.

**El error IDX10517 solo aparece cuando se modificó JwtTokenService.cs para agregar `KeyId` al `SymmetricSecurityKey`** — cambio introducido no autorizadamente durante el diagnóstico inicial. Con el código original (sin `KeyId`), **no hay error IDX10517**.

**No existe `AddJwtBearer` de ASP.NET Core.** No existe `IssuerSigningKeys`, `IssuerSigningKeyResolver`, `ConfigurationManager`, ni `ConfigureTokenValidation` invocado. El pipeline es exclusivamente CBP Authentication middleware.

**ROOT CAUSE**: `UseHttpsRedirection()` en `Program.cs:233` — no es bug de JWT.

## 3. BUG-017.1.3 Description

**Título**: Los endpoints autenticados fallan porque el middleware JWT rechaza tokens emitidos por la aplicación con IDX10517.

**Síntoma**: `POST /api/auth/login` (AllowAnonymous) → retorna JWT → cualquier endpoint `[Authorize]` con ese JWT → 401.

**Error en logs**: `IDX10517: Signature validation failed. The token's kid is missing. Keys tried: '...SymmetricSecurityKey, KeyId: 'PassPlat-HS256', ...'`

**Afecta**: Todos los endpoints `[Authorize]`, incluyendo `POST /api/auth/switch-tenant/{idTenant}` que funcionaban correctamente durante A1.8.

**Impacto**: Bloquea la certificación de A1.9.

| `NuGet Microsoft.AspNetCore.Authentication.JwtBearer` | No instalado |

### 7.2. Conclusión

**No existe ASP.NET Core JWT Bearer handler.** No hay un pipeline paralelo de autenticación JWT. El único pipeline es CBP Authentication middleware (`UseCbpAuthentication` + `JwtAuthenticationOperator` + `JwtTokenService`).

### 7.3. ¿Qué handler produce el 401?

El flujo es:
1. CBP Authentication middleware (`AuthenticationMiddleware`) se ejecuta primero
2. Si `JwtAuthenticationOperator.AuthenticateAsync()` falla (token inválido o ausente), y `AutoChallenge=false` → middleware **continúa** sin autenticar
3. ASP.NET Core `UseAuthorization()` detecta `context.User.Identity?.IsAuthenticated != true` → llama `ForbidAsync()` sobre `DefaultForbidScheme = "CbpFallback"`
4. `CbpForbidHandler.ForbidAsync()` → retorna 401

No hay `AuthenticateAsync()` de ASP.NET Core involucrado porque no hay `DefaultAuthenticateScheme`.

## 11. JWT Validation Path

### 11.1. ¿Quién valida el JWT?

El único validador es **`JwtTokenService.ValidateToken()`**, invocado por `JwtAuthenticationOperator.AuthenticateAsync()`.

### 11.2. Código de JwtAuthenticationOperator

```csharp
// JwtAuthenticationOperator.cs
public Task<AuthenticationResult> AuthenticateAsync(HttpContext context)
{
    var authHeader = context.Request.Headers.Authorization.ToString();
    if (string.IsNullOrEmpty(authHeader))
        return Task.FromResult(AuthenticationResult.Skip());

    if (!authHeader.StartsWith(_options.TokenPrefix, StringComparison.OrdinalIgnoreCase))
        return Task.FromResult(AuthenticationResult.Skip());

    var token = authHeader[_options.TokenPrefix.Length..].Trim();
    var principal = _tokenService.ValidateToken(token, out var validated);
    if (principal == null)
        return Task.FromResult(AuthenticationResult.Fail("INVALID_TOKEN", ...));

    var identity = principal.Identities.FirstOrDefault();
    if (identity == null || !identity.IsAuthenticated)
        return Task.FromResult(AuthenticationResult.Fail("NOT_AUTHENTICATED", ...));

    return Task.FromResult(AuthenticationResult.Success(principal));
}
```

### 11.3. Código de JwtTokenService.ValidateToken

```csharp
// JwtTokenService.cs:84-113
public ClaimsPrincipal? ValidateToken(string token, out SecurityToken? validatedToken)
{
    try
    {
        var principal = Handler.ValidateToken(token, _validationParams, out validatedToken);
        _logger.LogDebug("JWT validation succeeded");
        return principal;
    }
    catch (SecurityTokenExpiredException ex)
    {
        _logger.LogWarning(ex, "JWT is expired");
        validatedToken = null;
        return null;
    }
    catch (SecurityTokenException ex)
    {
        _logger.LogWarning(ex, "JWT validation failed: {Message}", ex.Message);
        validatedToken = null;
        return null;
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "Unexpected error during JWT validation");
        validatedToken = null;
        return null;
    }
}
```

### 11.5. ¿De dónde viene IDX10517?

**IDX10517 viene exclusivamente de `JwtTokenService.ValidateToken()`**, concretamente de `JwtSecurityTokenHandler.ValidateToken()`.

El stack trace confirmado es:

```
System.IdentityModel.Tokens.Jwt.JwtSecurityTokenHandler.ValidateSignature(JsonWebToken jwt, ...)
    → ValidateSignatureAndIssuerSecurityKey(...)
    → ValidateJWS(...)
    → ValidateToken(String token, TokenValidationParameters validationParameters, out SecurityToken validatedToken)
    → CBP.Authentication.JwtBearer.JwtTokenService.ValidateToken(String token, out SecurityToken validatedToken)
```

**No existe ASP.NET Core `JwtBearerHandler` que pueda producir este error.**

### 11.6. ¿Por qué aparece IDX10517?

**Condición exacta** para que IdentityModel 8.x produzca `IDX10517` con un JWT HS256:

```
Token header: {"alg":"HS256","typ":"JWT"}  (sin kid)
IssuerSigningKey.KeyId = "PassPlat-HS256"    (NO vacío)
```

Cuando `KeyId` no es `string.Empty`, el validador espera que el token tenga `kid` para hacer matching. Como el token no tiene `kid`, falla con `IDX10517`.

**Con `KeyId = ""` (default)**: No requiere matching → usa la key directamente → **NO produce IDX10517**.

### 11.7. Conclusión

**IDX10517 solo aparece cuando se modifica `SymmetricSecurityKey.KeyId`**. Con el código original (sin KeyId), es imposible obtener este error.

## 17. Root Cause

### 17.1. Clasificación

**ROOT CAUSE: H — Otra causa (infraestructura, no JWT)**

### 17.2. Explicación

La causa raíz del problema reportado (endpoints `[Authorize]` retornan 401) es **`UseHttpsRedirection()`** en `Program.cs:233`.

```
Request HTTP (puerto 5000)
  │
  ▼
UseHttpsRedirection() — 307 Redirect a HTTPS (puerto 5001)
  │
  ▼
Request a HTTPS (puerto 5001) SIN Authorization header
  │  (el cliente no reenvía el header en la redirección cross-scheme)
  ▼
CBP Authentication — no encuentra Bearer token → Skip
  │
  ▼
Authorization — no hay usuario autenticado → 401
```

**No es un bug del pipeline JWT.** El JWT se emite correctamente, se valida correctamente, y la autenticación funciona perfectamente cuando la request llega directamente a HTTPS.

### 17.3. ¿Por qué se reportó como IDX10517?

El error `IDX10517` observado en logs fue causado por **modificación no autorizada de `JwtTokenService.cs`** durante el diagnóstico inicial, donde se agregó:

```csharp
// CAMBIO NO AUTORIZADO — ya revertido
new SymmetricSecurityKey(Encoding.UTF8.GetBytes(options.SecretKey))
{
    KeyId = "PassPlat-HS256"
};
```

Este cambio hizo que:
1. `SymmetricSecurityKey.KeyId = "PassPlat-HS256"` (no vacío)
2. IdentityModel 8.x interpreta: "la key tiene KeyId → el token debe tener kid"
3. El token generado no tiene `kid` → `IDX10517`

Con el código original (sin KeyId), **IDX10517 no puede ocurrir**.

### 17.4. Confirmación adicional

- `ConfigureTokenValidation` nunca es invocado → no modifica parámetros de validación
- No existe `AddJwtBearer` → no hay pipeline paralelo con configuración diferente
- No existe `IssuerSigningKeyResolver`, `IssuerSigningKeys`, ni `ConfigurationManager` → resolución de clave directa
- El JWT header real (`{"alg":"HS256","typ":"JWT"}`) no tiene `kid`, y la validación no lo requiere

**Ruta**: `D:\CODIGOS\CBP\CBP.Authentication\CBP.Authentication.JwtBearer\JwtTokenService.cs`  
**Namespace**: `CBP.Authentication.JwtBearer`  
**Clase**: `JwtTokenService : IJwtTokenService`

```csharp
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Security.Cryptography;
using System.Text;
using Microsoft.Extensions.Logging;
using Microsoft.IdentityModel.Tokens;

namespace CBP.Authentication.JwtBearer;

public class JwtTokenService : IJwtTokenService
{
    private static readonly JwtSecurityTokenHandler Handler = new()
    {
        SetDefaultTimesOnTokenCreation = false
    };

    private readonly JwtOptions _options;
    private readonly TokenValidationParameters _validationParams;
    private readonly ILogger<JwtTokenService> _logger;

    public JwtTokenService(JwtOptions options, ILogger<JwtTokenService> logger)
    {
        _options = options;
        _logger = logger;

        var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(options.SecretKey));
        // NOTA: key.KeyId = string.Empty (default) — NO establecido

        _validationParams = new TokenValidationParameters
        {
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = key,
            ValidateIssuer = !string.IsNullOrEmpty(options.Issuer),
            ValidIssuer = options.Issuer,
            ValidateAudience = !string.IsNullOrEmpty(options.Audience),
            ValidAudience = options.Audience,
            ValidateLifetime = true,
            ClockSkew = options.ClockSkew
        };

        options.ConfigureTokenValidation?.Invoke(_validationParams);
        // NOTA: ConfigureTokenValidation es null siempre — no modifica nada
    }

    public string GenerateToken(IEnumerable<Claim> claims)
    {
        var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_options.SecretKey));
        // NOTA: key.KeyId = string.Empty (default) — NO establecido
        // JWT header resultante: {"alg":"HS256","typ":"JWT"} (sin kid)

        var credentials = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

        var enrichedClaims = claims
            .Append(new Claim(JwtRegisteredClaimNames.Iat,
                DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString(),
                ClaimValueTypes.Integer64))
            .ToList();

        var token = new JwtSecurityToken(
            issuer: string.IsNullOrEmpty(_options.Issuer) ? null : _options.Issuer,
            audience: string.IsNullOrEmpty(_options.Audience) ? null : _options.Audience,
            claims: enrichedClaims,
            expires: DateTime.UtcNow.AddMinutes(_options.ExpirationMinutes),
            signingCredentials: credentials);

        var result = Handler.WriteToken(token);
        return result;
    }

    public string GenerateRefreshToken()
    {
        var bytes = RandomNumberGenerator.GetBytes(_options.RefreshTokenBytesLength);
        return Convert.ToBase64String(bytes);
    }

    public ClaimsPrincipal? ValidateToken(string token, out SecurityToken? validatedToken)
    {
        try
        {
            var principal = Handler.ValidateToken(token, _validationParams, out validatedToken);
            _logger.LogDebug("JWT validation succeeded");
            return principal;
        }
        catch (SecurityTokenExpiredException ex)
        {
            _logger.LogWarning(ex, "JWT is expired");
            validatedToken = null;
            return null;
        }
        catch (SecurityTokenException ex)
        {
            _logger.LogWarning(ex, "JWT validation failed: {Message}", ex.Message);
            validatedToken = null;
            return null;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Unexpected error during JWT validation");
            validatedToken = null;
            return null;
        }
    }
}
```

```csharp
using System.Security.Claims;
using Microsoft.AspNetCore.Http;
using Microsoft.Extensions.Logging;

namespace CBP.Authentication.JwtBearer;

public class JwtAuthenticationOperator : IAuthenticationOperator
{
    private readonly JwtOptions _options;
    private readonly IJwtTokenService _tokenService;
    private readonly ILogger<JwtAuthenticationOperator> _logger;

    public string Scheme => "JwtBearer";

    public JwtAuthenticationOperator(
        JwtOptions options,
        IJwtTokenService tokenService,
        ILogger<JwtAuthenticationOperator> logger)
    {
        _options = options;
        _tokenService = tokenService;
        _logger = logger;
    }

    public Task<AuthenticationResult> AuthenticateAsync(HttpContext context)
    {
        var authHeader = context.Request.Headers.Authorization.ToString();
        if (string.IsNullOrEmpty(authHeader))
            return Task.FromResult(AuthenticationResult.Skip());

        if (!authHeader.StartsWith(_options.TokenPrefix, StringComparison.OrdinalIgnoreCase))
            return Task.FromResult(AuthenticationResult.Skip());

        var token = authHeader[_options.TokenPrefix.Length..].Trim();
        var principal = _tokenService.ValidateToken(token, out var validated);
        if (principal == null)
            return Task.FromResult(AuthenticationResult.Fail("INVALID_TOKEN",
                "Token validation failed"));

        var identity = principal.Identities.FirstOrDefault();
        if (identity == null || !identity.IsAuthenticated)
            return Task.FromResult(AuthenticationResult.Fail("NOT_AUTHENTICATED",
                "Principal is not authenticated"));

        return Task.FromResult(
            AuthenticationResult.Success(principal));
    }

    public Task ChallengeAsync(HttpContext context)
    {
        context.Response.StatusCode = 401;
        return Task.CompletedTask;
    }

    public Task ForbidAsync(HttpContext context)
    {
        context.Response.StatusCode = 401;
        return Task.CompletedTask;
    }
}
```

```csharp
using Microsoft.AspNetCore.Http;
using Microsoft.Extensions.Logging;

namespace CBP.Authentication.Middleware;

public class AuthenticationMiddleware
{
    private readonly RequestDelegate _next;
    private readonly CbpAuthenticationOptions _options;
    private readonly ILogger<AuthenticationMiddleware> _logger;

    public AuthenticationMiddleware(
        RequestDelegate next,
        CbpAuthenticationOptions options,
        ILogger<AuthenticationMiddleware> logger)
    {
        _next = next;
        _options = options;
        _logger = logger;
    }

    public async Task InvokeAsync(HttpContext context, IEnumerable<IAuthenticationOperator> operators)
    {
        AuthenticationResult? firstFailure = null;
        IAuthenticationOperator? firstFailureOperator = null;

        foreach (var op in operators)
        {
            var result = await op.AuthenticateAsync(context);

            if (result.Succeeded)
            {
                _logger.LogDebug(
                    "Authentication succeeded via {Scheme} for {RemoteIp}",
                    op.Scheme, context.Connection.RemoteIpAddress);

                context.User = result.Principal!;
                await _next(context);
                return;
            }

            if (result.Failed)
            {
                _logger.LogWarning(
                    "Authentication failed via {Scheme}: {Code} — {Message} ({RemoteIp})",
                    op.Scheme, result.FailureCode, result.FailureMessage,
                    context.Connection.RemoteIpAddress);

                firstFailure ??= result;
                firstFailureOperator ??= op;

                if (_options.AutoChallenge)
                {
                    await InvokeChallengeAsync(context, op, result);
                    return;
                }
            }

            if (result.Skipped)
            {
                _logger.LogDebug("Authentication skipped by {Scheme}", op.Scheme);
            }
        }

        if (firstFailure != null && firstFailureOperator != null
            && _options.AutoChallenge && operators.Any())
        {
            await InvokeChallengeAsync(context, firstFailureOperator, firstFailure);
            return;
        }

        _logger.LogDebug("No authentication operator matched for {RemoteIp}",
            context.Connection.RemoteIpAddress);
        await _next(context);
    }

    private async Task InvokeChallengeAsync(
        HttpContext context,
        IAuthenticationOperator op,
        AuthenticationResult result)
    {
        context.Items["CbpAuthFailure"] = result;

        if (_options.OnChallenge != null)
        {
            await _options.OnChallenge(context, op, result);
            return;
        }

        await op.ChallengeAsync(context);
    }
}
```

```csharp
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Security.Cryptography;
using System.Text;
using CBP.Authentication.JwtBearer;
using Microsoft.Extensions.Logging;

namespace PassPlat.Aplicacion.Services.Authentication;

public sealed class AuthenticationTokenIssuer
{
    private readonly IJwtTokenService _jwtService;
    private readonly JwtOptions _jwtOptions;
    private readonly ILogger<AuthenticationTokenIssuer> _logger;

    public AuthenticationTokenIssuer(
        IJwtTokenService jwtService,
        JwtOptions jwtOptions,
        ILogger<AuthenticationTokenIssuer> logger)
    {
        _jwtService = jwtService;
        _jwtOptions = jwtOptions;
        _logger = logger;
    }

    public AuthenticationTokenGenerationResult Generate(
        AuthenticationContext context,
        IReadOnlyCollection<Claim> permisoClaims)
    {
        var jti = Guid.NewGuid().ToString();

        var claims = BuildIdentityClaims(context, jti);
        claims.AddRange(permisoClaims);

        var accessToken = _jwtService.GenerateToken(claims);
        var refreshToken = _jwtService.GenerateRefreshToken();
        var refreshHash = HashSHA256(refreshToken);
        var expiresAt = DateTime.UtcNow.AddMinutes(
            _jwtOptions.RefreshTokenExpirationMinutes);

        return new AuthenticationTokenGenerationResult(
            accessToken, refreshToken, refreshHash, jti, expiresAt);
    }

    private static List<Claim> BuildIdentityClaims(
        AuthenticationContext context, string jti)
    {
        var claims = new List<Claim>
        {
            new(ClaimTypes.NameIdentifier, context.IdUsuario.ToString()),
            new("IdApp", context.IdApp.ToString()),
            new(JwtRegisteredClaimNames.Jti, jti)
        };

        if (context.IdTenant.HasValue)
            claims.Add(new Claim("TenantId", context.IdTenant.Value.ToString()));

        if (context.IdUsuarioTenant.HasValue)
            claims.Add(new Claim("UsuarioTenantId", context.IdUsuarioTenant.Value.ToString()));

        if (context.EsSistema)
            claims.Add(new Claim("is_system", "true"));

        return claims;
    }

    private static string HashSHA256(string input)
    {
        var bytes = SHA256.HashData(Encoding.UTF8.GetBytes(input));
        return Convert.ToHexStringLower(bytes);
    }
}
```
