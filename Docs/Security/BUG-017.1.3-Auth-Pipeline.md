# BUG-017.1.3 — CBP.Authentication Authorization Pipeline

| Campo | Valor |
|-------|-------|
| **ID** | BUG-017.1.3 |
| **Área** | CBP.Authentication |
| **Severidad** | Alta |
| **Prioridad** | Alta |
| **Estado** | Pendiente de diagnóstico |
| **Regresión** | No confirmada |
| **Reportado** | 2026-07-19, durante validación Playwright Sprint A (v17.1.2) |
| **Impacto** | Endpoints `[Authorize]` retornan 401 pese a JWT válido |
| **Afecta** | Playwright (6 pruebas de FASE 14), endpoints `/api/providen` y `/api/usuarios` |

---

## Síntoma

1. Login (`POST /api/auth/login`) genera JWT válido.
2. Endpoints con `[Authorize]` retornan `401 Unauthorized` con `ProblemDetails`.
3. `[AllowAnonymous]` funciona correctamente.
4. El JWT decodifica correctamente (iss: `PassPlat`, aud: `PassPlat`, exp: futuro, claims estándar presentes).

## Evidencia

- **6 tests Playwright bloqueados** (FASE 14: tests 2, 3, 4, 7, 12, 14).
- **7 tests Sprint A pasan** — el bug es preexistente, no causado por cambios de endurecimiento OAuth.
- **No hay logs de warning** de `CBP.Authentication.JwtBearer` pese a que Serilog está configurado con nivel `Information` (Default), que es inferior a `Warning`.

## Hipótesis (ordenadas por probabilidad)

1. **JwtAuthenticationOperator no se ejecuta** — `IEnumerable<IAuthenticationOperator>` está vacío en DI, el middleware itera cero operadores y pasa sin autenticar.
2. **JwtAuthenticationOperator retorna `Skip()`** — no encuentra el header `Authorization: Bearer` o el prefix no coincide (posible formato inesperado).
3. **UseCbpAuthentication() asigna `context.User` incorrectamente** — el middleware CBP no sincroniza correctamente el principal con el pipeline de ASP.NET Core.
4. **Falta de `DefaultAuthenticateScheme`** — `AddAuthentication()` solo setea `DefaultForbidScheme = "CbpFallback"`. Sin `DefaultAuthenticateScheme`, `[Authorize]` no sabe qué handler usar.
5. **Orden del middleware** — `UseCbpAuthentication()` → `UseAuthorization()` es correcto, pero la ausencia de `app.UseAuthentication()` estándar impide que ASP.NET Core reconozca al usuario autenticado.

## Pipeline Actual (Program.cs:233-234)

```csharp
app.UseCbpAuthentication();   // CBP custom auth middleware
app.UseAuthorization();       // ASP.NET Core authorization
// NOTA: app.UseAuthentication() NO está presente
```

## Configuración DI (Program.cs)

```csharp
services.AddCbpAuthentication(o => o.AutoChallenge = false);
services.AddJwtOperator(options => {
    options.SecretKey = jwtSecret;
    options.Issuer = "PassPlat";
    options.Audience = "PassPlat";
    options.TokenLifetimeMinutes = 60;
});
services.AddAuthentication(o => {
    o.DefaultForbidScheme = "CbpFallback";
    // NOTA: DefaultAuthenticateScheme y DefaultChallengeScheme NO están configurados
});
```

## Diagnóstico Propuesto

### Paso 1: Verificar DI — ¿Cuántos `IAuthenticationOperator` registrados?

```csharp
// Log temporal en Program.cs, tras AddCbpAuthentication
var operatorCount = app.Services.GetRequiredService<IEnumerable<IAuthenticationOperator>>().Count();
logger.LogInformation("IAuthenticationOperator registrados: {Count}", operatorCount);
// Esperado: 1 (JwtAuthenticationOperator)
```

### Paso 2: Instrumentar AuthenticationMiddleware

Agregar logs en `CBP.Authentication.Abstractions/Middleware/AuthenticationMiddleware.cs`:

```csharp
// Antes del foreach
logger.LogInformation("AuthenticationMiddleware: {OperatorCount} operadores registrados", operators.Count());

// En cada operador
logger.LogInformation("Ejecutando operador: {OperatorType}", op.GetType().Name);

// Después del resultado
if (result.IsSuccess)
    logger.LogInformation("Operador {Op} -> Success. User.Identity.IsAuthenticated: {Auth}",
        op.GetType().Name, context.User?.Identity?.IsAuthenticated);
else if (result.IsSkipped)
    logger.LogInformation("Operador {Op} -> Skip", op.GetType().Name);
else
    logger.LogWarning("Operador {Op} -> Fail: {Error}", op.GetType().Name, result.Failure?.Message);

// Antes de UseAuthorization
logger.LogInformation("Antes de UseAuthorization: HttpContext.User = {User}, IsAuthenticated = {Auth}",
    context.User?.Identity?.Name, context.User?.Identity?.IsAuthenticated);
```

### Paso 3: Habilitar Debug logging para CBP.Authentication

En `appsettings.json`:
```json
"Serilog": {
  "MinimumLevel": {
    "Override": {
      "CBP.Authentication": "Debug"
    }
  }
}
```
