## 7. Guard de gobernanza reutilizable (D4/D5)

### 7.1 Requisito

Convertir la regla documental `EventCatalog.md L14–16` (*"cualquier EventName usado en el código DEBE estar registrado; un evento usado y no catalogado es violación"*) en una garantía ejecutable que prevenga la **reaparición** de V-02 (`EventName = "Event_Queued"` literal libre).

### 7.2 Por qué NO es suficiente otro enfoque

- **Guard runtime**: imposible. `ILoggerService` recibe `string` plano — en runtime es indistinguible si un `EventName` provino de una constante o de un literal. El guard DEBE ser análisis estático de fuentes.
- **Analyzer Roslyn en CBP**: técnicamente la garantía más fuerte, pero modificaría el framework → **EXCLUIDO** (STOP condition S33.2 #4). Diferido como evolución opcional post-S33.
- **Regex simple** (patrón `OutboxProcessorEventNamesTests`): frágil ante multi-línea/comentarios/strings de otro alcance; no distingue `EventName = "x"` dentro de `LogEvent` vs otros objetos. Roslyn es superior.

### 7.3 Diseño — contrato de la clase reutilizable

**Ubicación**: `PassPlat.Aplicacion.Test\Tests\Logging\` (nuevo)

```csharp
public interface IEventNameCatalogGuard
{
    IReadOnlyList<EventNameLiteralViolation> Scan(
        IEnumerable<string> sourceFiles,
        IReadOnlySet<string> catalogEventValues);
}

public sealed record EventNameLiteralViolation(
    string FilePath,
    int Line,
    string LiteralValue,
    string SuggestedConstant);
```

**Implementación**: `RoslynEventNameCatalogGuard : IEventNameCatalogGuard`

**Algoritmo**:
1. Parsear cada `.cs` con `CSharpSyntaxTree.ParseText(...)`.
2. Recorrer nodos buscando `AssignmentExpressionSyntax` donde el **identificador izquierdo** sea `EventName` (método `IsKind(SyntaxKind.SimpleAssignmentExpression)` y `expression.Left` es `IdentifierName("EventName")`).
3. Si el **RHS** es `LiteralExpressionSyntax` de tipo string (`SyntaxKind.StringLiteralExpression`):
   - valor ∈ `catalogEventValues` → **VIOLACIÓN** (`SuggestedConstant` = nombre de campo cuyo valor coincida, vía reflexión inversa).
   - valor ∉ set → **NO violación** (conservador, D5).
4. Si RHS NO es literal (identificador, acceso a miembro `LoggingEvents.X`, llamada, variable) → **null (ignorado)**: nombres dinámicos legítimos no se castigan.

### 7.4 Derive del catálogo — por REFLEXIÓN (fuente única, D5)

```csharp
var catalogValues = typeof(LoggingEvents)
    .GetFields(BindingFlags.Public | BindingFlags.Static | BindingFlags.FlattenHierarchy)
    .Where(f => f.IsLiteral && f.FieldType == typeof(string))
    .ToDictionary(
        f => (string)f.GetValue(null)!,
        f => f.Name);   // valor → nombre de constante (para SuggestedConstant)
```

- **28 constantes actuales** (verificado por Roslyn: `sharplens get_type_members` → 28 Fields). Tras S33.2 → 29.
- Auto-actualizante: cuando se añada `EventQueued` la reflexión lo captura sin tocar el guard.
- `T5` (catálogo↔constante) también deriva de aquí, comparando contra el parsing del `.md`.
