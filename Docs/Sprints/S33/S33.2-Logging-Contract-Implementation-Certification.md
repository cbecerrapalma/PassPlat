### Fixes aplicados en primer run (2 tests rojos → 7/7)
- **T5A**: el sample usaba initializer **anónimo** (`new { EventName = ... }`) → Roslyn lo modela como `AnonymousObjectMemberDeclarator`, no `AssignmentExpression` → el guard (correctamente) no lo detecta. Corregido el sample a object initializer real (`new LogEvent { EventName = "Event_Queued" }`), representativo del código de producción.
- **T5B**: el regex de extracción de docTokens solo capturaba tokens con underscore; `Logout` (single-word, sin `_`) quedaba como "sin documentar". Ampliado a **todos** los tokens backticked del doc.
