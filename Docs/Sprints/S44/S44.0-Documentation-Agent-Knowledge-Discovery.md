## Objective

Re-audit the physical documentation tree, its navigability, duplication risk, stale states and present context cost before designing any migration. This document is evidence and a decision input; it does not authorize a move, rename, deletion, AGENTS rewrite or source-code change.

## Method and limits

The prescribed MCP sequence (`sequential-thinking`, `supermemory`, `sharplens`, then `context7` only for external APIs) is not available in this execution environment. The equivalent local, read-only evidence collected was: filesystem inventory; full-text inspection of `AGENTS.md`, `Docs/README.md`, all current `AgentsIA` documents and S43.2; link-destination resolution; directory/path classification; duplicate/stale candidate queries; and build/test baselines. No external API documentation was needed.

The link resolver extracted Markdown destinations, removed anchors, resolved relative paths from the source document (or repository root for `Docs/...` and `AGENTS.md`), and tested the resulting filesystem target. It intentionally excludes HTTP(S), mailto, same-document anchors and the known external SQL source `D:\CODIGOS\BBDD\...`. It is stronger than a path-prefix regex, but does **not** prove informal prose/backtick references or semantic equivalence. Those are explicitly retained as S44.1 work.

## G6 / G7 / G9: duplication, stale state and placement findings

### Confirmed structural findings

1. The archive is correctly separated physically, but `AGENTS.md` still points users to the 1,243-line `ANCHORED-SUMMARIES-ARCHIVE.md` in its operational sprint index. This contradicts the target “historical lookup only” route and makes accidental context loading likely.
2. Historical sprint-like artefacts remain in `Docs/Architecture/` (`S6`–`S14`, `A0.*`, `A1.*`, FASE17.5) and in `Operations/` / `Testing/Audit/`. They cannot be moved merely by filename: some may be permanent decisions or certification baselines. All are **REQUIRES-DESIGN**.
3. Evidence is materially split: `Docs/Evidence/` holds logs/manifests while `Docs/audit/` holds 135 visual evidence assets. The latter is an **EVIDENCE location candidate**, not proof that it may be moved; the immutable-evidence rule applies.
4. `Docs/ui/frontend-dev-LEGACY.md` and `Docs/ui/screens-LEGACY.md` are co-located with active documents and described by `AgentsIA/Testing.md` as legacy/obsolete. They are **ARCHIVE-CANDIDATE**, not removal candidates, until semantic and reference review is complete.
5. The current S43.2 report says S43.3 is “NOT AUTHORIZED / no requerido”; it is historical. The root AGENTS sprint registry also labels S32.0 “DISCOVERY” although S32.2 exists. Both are stale-state hazards if loaded as current operational status.

## G11–G14: proposed target (not authorized for implementation)

### AgentsIA taxonomy

Keep the current six files as conceptual starting points, but redesign them to be short operational routers with `Purpose`, `Scope`, `Mandatory Rules`, `Patterns`, `Anti-patterns`, `Canonical Contracts`, `Load Next`, `Do Not Load`, and `Historical References`.

Proposed initial domains to validate in S44.1: `Architecture`, `Contracts`, `Development`, `Testing`, `Operations`, `Domain`, `Data`, `Database`, `Security`, `Authentication`, `Authorization`, `MultiTenant`, `Email`, `OAuth`, `Events`, `Logging`, `Observability`, `Caching`, `BackgroundJobs`, `Outbox`, `UI`, `WebAPI`, `Configuration`; with `Framework/{CBP,CBPData,CBPEvents,CBPLogging,CBPAuthentication,CBPCaching,CBPSecurity}` and `Navigation/{Sprints,PermanentDocs,Evidence,Troubleshooting}`. Consolidation is allowed only when shared load paths and one accountable source of truth are demonstrated.

### AGENTS target

The target AGENTS must contain only: mission; mandatory workflow; stop conditions; build/test commands; solution map; condensed architecture/security/data/testing/documentation invariants; an explicit lazy-load router; and a compact dated baseline. It must remove the historical registry and avoid copying AgentsIA or Framework content. The target is 400–700 lines and under 750 lines, subject to S44.1 content design.

### Docs target

`Architecture` is permanent current architecture/ADRs; `Framework` remains stable contractual documentation; `Evidence` is immutable; `Sprints/SXX` is execution history; `Sprints/ARCHIVE` is non-operational history; and `AgentsIA` is operational routing. Existing `Application`, `Data`, `Domain`, `Database`, `UI`, `Testing`, `Operations`, `Security`, `System` and `Troubleshooting` need a source-of-truth map before being moved, merged or referenced. No current classification grants permission to alter them.
