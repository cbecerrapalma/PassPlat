## 3. Decisión — Opción A

**Agregar `CBP.Security.Password.Tests.csproj` a `CBP.slnx`. No crear solución paralela.**

S45.0 evaluó A-D con 7 dimensiones (cambios/riesgo/CPM/CI/consumers/esfuerzo/reversibilidad):
- **A:** 1 línea slnx, riesgo mínimo, CPM ✅, CI puerta única, consumers nulo, esfuerzo <5 min, reversible alta — **recomendada**.
- B/C: nueva slnx/slnf dedicada — más artefactos, 2 pipelines, riesgo divergencia, sin beneficio adicional.
- D: no modificar — deja deuda, CI sin tests CBP.

Opción A es el mínimo cambio con máximo valor de certificación y preserva `ManagePackageVersionsCentrally=true` sin `VersionOverride` nuevo (el csproj ya usa `PrivateAssets=all` correctamente).

## 8. FASE 5 — Reversibilidad

**Rollback = eliminar únicamente la entrada en `CBP.slnx`:**

```powershell
# 1. Revertir slnx (sin borrar el csproj físico)
dotnet sln D:\CODIGOS\CBP\CBP.slnx remove D:\CODIGOS\CBP\CBP.Infraestructure\CBP.Security\CBP.Security.Password.Tests\CBP.Security.Password.Tests.csproj
# o: git restore CBP.slnx

# 2. Verificar que el csproj físico permanece intacto
Test-Path D:\CODIGOS\CBP\CBP.Infraestructure\CBP.Security\CBP.Security.Password.Tests\CBP.Security.Password.Tests.csproj  # → True

# 3. Reverificar
dotnet build D:\CODIGOS\CBP\CBP.slnx -v q                          # → 0 errores (24 proyectos)
dotnet test D:\CODIGOS\CBP\CBP.Infraestructure\CBP.Security\CBP.Security.Password.Tests\CBP.Security.Password.Tests.csproj --nologo  # → 56/56
```

**No eliminar el proyecto de tests.** El rollback es 1 línea slnx, reversible en <1 min. `CBP.slnx` mtime volvería a 21-07-2026 si se restaura vía `git`.
