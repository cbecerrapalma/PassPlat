## 3. Problema (S46.0 G4)

`EmailTemplateDialog.razor:26` → `MudTextField Lines="12"` para `CuerpoHtml` (textarea plano) sin **highlight HTML**, **indentación**, **folding**, **búsqueda/reemplazo**, **formateo**, **validación `{{...}}`**. `HtmlPreviewDialog.razor:9` → `@((MarkupString)ContentText)` en `MudPaper` — sin `iframe sandbox` (XSS P2). `EmailTemplateService` sin validación `{{AppName}}`/`{{UserName}}`/`{{MfaCode}}` ni sanitización `<script>`/`on*`/`javascript:`.

DTO `EmailTemplateDto.CuerpoHtml` `HasMaxLength(-1)` almacena HTML intacto, `Asunto`/`CuerpoTexto` separados, `VariablesDoc` opcional no validado. Pipeline `PassPlatEmailService` (Fluid `{{...}}` → MailKit) espera HTML completo con tablas inline para Gmail/Outlook.

**Clasificación:** `FUNCIONAL-INCOMPLETO / UX` P2 + `SEGURIDAD` P2 — S46.1 debe diseñar híbrido.

## 5. Evaluación BlazorMonaco 3.5.0 (Context7 `/serdarciplak/blazormonaco`)

**Paquete:** `https://www.nuget.org/packages/BlazorMonaco` **3.5.0** — `net10.0`, **MIT**, Monaco 0.55.1, `StandaloneCodeEditor`, 449 snippets, High rep.

**Integración requerida (precisa para S46.2 si se aprueba):**
```html
<!-- wwwroot/index.html head, antes de blazor.webassembly.js -->
<script src="_content/BlazorMonaco/jsInterop.js"></script>
<script src="_content/BlazorMonaco/lib/monaco-editor/min/vs/loader.js"></script>
<script src="_content/BlazorMonaco/lib/monaco-editor/min/vs/editor/editor.main.js"></script>
```
```razor
@rendermode InteractiveAuto // WASM: InteractiveAuto/InteractiveWebAssembly
<StandaloneCodeEditor @ref="_editor"
  ConstructionOptions="EditorConstructionOptions"
  OnDidInit="EditorOnDidInit" OnDidChangeModelContent="OnContentChanged" />
```
```csharp
private StandaloneEditorConstructionOptions EditorConstructionOptions(StandaloneCodeEditor ed) => new() {
  Language = "html", Theme = "vs", AutomaticLayout = true,
  Minimap = new() { Enabled = false }, // bundle
  Folding = true, WordWrap = "on", TabSize = 2
};
```

| Requisito S46.1 | Evaluación BlazorMonaco |
|---|---|
| **Source HTML highlight/indent/folding/search/format** | ✅ `language:"html"` → tokenización HTML, `AutomaticLayout`, `Folding:true`, `Ctrl+F` built-in, `editor.action.formatDocument` (js-beautify implícito), `TabSize 2`, `WordWrap on` |
|  |  |
| **Placeholders `{{AppName}}` preservación** | ✅ Source no transforma — `{{AppName}}` es texto plano en modelo Monaco; no `&lbrace;` como WYSIWYG. Custom `Monarch` tokenizer puede colorear `{{.*}}` sin romper (registrable `monaco.languages.setMonarchTokensProvider`) |
| **Validación HTML** | ✅ Monaco `html` valida tags sin cerrar (squiggles), S46.1 validará además vía `Fluid` parse + `HtmlAgilityPack` allowlist `table/tr/td/div/h1-h6/p/a/img` |
| **Validación placeholders vs soportadas** | ✅ Regex `{{(.*?)}}` vs allowlist S46.0 `UserName/ResetLink/ExpiraMinutos/MfaCode/AppName/LoginUrl/AlertMessage/IP/FechaHora/Minutes/TipoCambio` + `extraVariables` dinámicas; `VariablesDoc` como doc, no fuente de verdad |
| **Preview iframe sandbox** | ✅ Diseño S46.1: ` <iframe sandbox="" srcdoc="@SanitizedHtml" csp="default-src 'none'; style-src 'unsafe-inline'">` — nunca `MarkupString` en DOM principal. Eliminar `script/on*/javascript:iframe/embed/object/img onerror` antes |
| **Interactive + IJSRuntime + SafeInvokeAsync** | ⚠️ **Verificar en S46.1** — Docs requieren `@rendermode InteractiveServer` y `SafeInvokeAsync("blazorMonaco.editor.create", ...)` con `try/catch ObjectDisposedException`. WASM actual es `WebAssemblyHostBuilder` sin `Interactive*` explícito; `BlazorMonaco` declara overloads `Obsolete WASM-only` → usar `IJSRuntime` dual. S46.1 debe probar `StandaloneCodeEditor` en `Index.razor` WASM con `IJSRuntime` inyectado y `Dispose` en `MudDialog.Close` |
| **Bundle / Monaco recursos** | ⚠️ `editor.main.js` ~2-3 MB + `loader.js` + `jsInterop.js` — cacheable, pero WASM download inicial crece. Con `Minimap:false` y `vs/editor` solo html, bundle aceptable para `/email-templates` (admin, no ruta crítica). S46.1 medirá `blazor.boot.json` delta |
| **Navegación / MudDialog** | ⚠️ Enhanced navigation `.NET10` + `MudDialog` open/close deben `Dispose` Monaco: `OnAfterRenderAsync` → `CreateModel`, `DisposeAsync` → `SafeInvokeAsync("dispose")`, manejo `NavigationManager.LocationChanged`. S46.1 probará reapertura dialog sin `JS interop ObjectDisposedException` |
| **Licencia MIT sin coste** | ✅ **MIT**, `LICENSE` en repo, `net10.0` target, `0.55.1` Monaco — cumple D-EDITOR-01 |
| **MudBlazor 9.8.0 coexistencia** | ✅ Monaco es `div` absoluto, no `MudTextField` — `MudDialog MaxWidth.Large` contiene `StandaloneCodeEditor` con `height: 400px`, sin clash `MudBlazor.min.css` |
| **.NET 10** | ✅ `net10.0` TFM, `Microsoft.AspNetCore.Components.WebAssembly 10.0.11` compatible |

**Riesgo BlazorMonaco:** JS interop + `Interactive` + `loader` ordering — si `WASM-only` path falla, **CodeMirror 6** (MIT, `codemirror 6` via `npm`, sin `loader.js`, `EditorView` + `html()` + `{{...}}` highlight via `StreamLanguage`) es alternativa con bundle menor y sin `vs/loader`.

## 6. Arquitectura propuesta (S46.1)

```
EmailTemplateDialog (MudDialog Large)
│
├── Tabs: [HTML] [Vista previa] [Validar]
│
├── HTML Source Editor (400-600px)
│   └── StandaloneCodeEditor (BlazorMonaco) — language html
│       ├── Toolbar: [Formatear] [Buscar] [Expandir]
│       ├── Placeholders detectados: {{AppName}} {{UserName}} {{MfaCode}} (chips)
│       └── Validación: squiggles HTML + diagnostics Fluid {{...}}
│
├── Validación HTML (onChange debounce 500ms)
│   └── HtmlAgilityPack — tags sin cerrar, tablas inline check
│
├── Validación {{Placeholders}} (onChange)
│   └── Regex {{(.*?)}} vs allowlist PassPlatEmailService + VariablesDoc (warning si desconocido)
│
├── Formatear HTML (toolbar)
│   └── Monaco editor.action.formatDocument (prettier/js-beautify, TabSize 2)
│
└── Vista previa segura (tab Preview)
    └── iframe sandbox="" srcdoc="@SanitizedHtml" CSP
        ├── Sanitizar: strip script/on*/javascript:/iframe/embed/object, allowlist table/tr/td/div/h1-p/a/img/style inline
        ├── Aislar: no same-DOM, no navegación, tratar como no confiable
        └── Render Fluid con variables dummy (UserName="Test") para preview real
```

**No usar WYSIWYG como fuente** — source preserva `table/tr/td` inline-styles para Gmail/Outlook; WYSIWYG normaliza a `div/span` y rompe `{{...}}`.
