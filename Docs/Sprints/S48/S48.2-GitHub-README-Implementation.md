```powershell

Copy-Item README.md $b\README.md.bak; Copy-Item .gitignore $b\

"@

# G3 limpieza segura — por ruta exacta, no patrón genérico
git rm --cached NUL2
git rm --cached api_pid.txt
git rm --cached prototype-roles-permisos.html
git rm --cached prototype-roles-permisos-user-view.html
git rm --cached -r .playwright-mcp
git rm --cached -r test-results
# (PassPlat.slnLaunch.user, build.log, api_bg.log, .tmp no tracked → did not match, correcto)
git add README.md .gitignore
git status --short  # M README.md, M .gitignore, D .playwright-mcp/*, D NUL2 etc., ?? Docs/Sprints/S47/48 (nuevos docs no incluidos en este diff)
git diff --cached --stat  # solo README/.gitignore/NUL2/prototype/playwright-mcp/test-results
```

**Distinción `rm --cached` vs físico:** `git rm --cached` elimina del índice pero mantiene archivo en workspace (reversible vía `git restore --staged` + `git checkout HEAD -- <path>` o `git log 9e800ef`). No `git clean -fd`.
