Jerarquía Activa
El rol Operador hereda permisos del rol Supervisor, quien hereda de Soporte. Todas las asignaciones se realizan automáticamente, sin necesidad de copiar permisos manualmente.
💡 Cómo funciona la herencia

Los roles en PassPlat pueden tener relaciones jerárquicas padre-hijo. Los roles hijos heredan automáticamente todos los permisos de sus roles padres, creando una cadena de herencia que puede ser profunda (Soporte → Supervisor → Operador → Asistente).

Esta estructura permite una gestión de permisos eficiente y escalable, donde los permisos solo necesitan asignarse una vez en el nivel superior de la jerarquía.

¿Necesitas administrar la jerarquía de roles?

El panel de administración permite visualizar, crear y modificar relaciones padre-hijo entre roles, gestionar permisos heredados y hacer cambios masivos en toda la jerarquía.

⚙️ Cómo se Configura la Jerarquía de Roles

📋 Tabla de Base de Datos

Crear: dbo.RolJerarquico(IdRol, IdRolPadre)
Índice Único: (IdRol, IdRolPadre)
Validación: IdRol ≠ IdRolPadre (sin ciclos)

🔧 Servicios API

POST /api/roles/{idRol}/jerarquia - Asignar padre
GET /api/roles/{idRol}/jerarquia - Obtener jerarquía
DELETE /api/roles/{idRol}/jerarquia/{idRolPadre} - Desasignar

🎨 Configuración UI

Panel de Administración
Vista de árbol editable, selector padre/hijo, vista previa de permisos
Validación en Tiempo Real
Detecta ciclos antes de guardar

💡 Configuración Típica

1. Definir Rol Padre Principal:
Insert into RolJerarquico values (2, null)
Soporte se convierte en rol raíz sin padre
2. Agregar Rol Hijo:
Insert into RolJerarquico values (3, 2)
Supervisor hereda todos los permisos de Soporte
3. Agregar Rol Sub-Hijo:
Insert into RolJerarquico values (4, 3)
Operador hereda de Supervisor (que hereda de Soporte)
